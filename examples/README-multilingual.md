# Multilingual static-analysis examples

These examples have no required dependencies, credentials, or network execution. Analyze them as source only:

```text
tokenoptipy build examples/php-token-graph --output php-example-out --language php
tokenoptipy build examples/java-token-graph --output java-example-out --language java
tokenoptipy build examples/cpp-token-graph --output cpp-example-out --language cpp
tokenoptipy build examples/dotnet-token-graph --output dotnet-example-out --language csharp
tokenoptipy build examples/go-token-graph --output go-example-out --language go
tokenoptipy build examples/rust-token-graph --output rust-example-out --language rust
tokenoptipy build examples/multilingual-token-graph --output multilingual-example-out --language all
```
