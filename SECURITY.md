# Security Policy

## Supported versions

Only the latest released minor version is supported during the alpha phase.

## Reporting a vulnerability

Do not open a public issue for a vulnerability involving secret exposure, arbitrary code execution, or unsafe prompt handling. Use GitHub private vulnerability reporting when enabled, or contact the maintainer privately.

TokenOptiPy processes prompts locally by default. Contributors must not add telemetry, uploads, or external model calls without explicit opt-in and documentation.
